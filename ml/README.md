# CartPlan ML

Модуль машинного обучения проекта CartPlan.

## Технологии

- Python 3.13
- Poetry — управление зависимостями и виртуальным окружением
- Pandas, NumPy, Scikit-learn
- Ruff — статический анализ и форматирование кода
- Pytest — автоматическое тестирование
- pre-commit — контроль качества перед коммитами

## Установка

Из корневого каталога репозитория:

```powershell
poetry -C ml install
```

## Запуск тестов

```powershell
poetry -C ml run pytest -v
```

## Проверка кода

```powershell
poetry -C ml run pre-commit run --all-files
```

## Реализованная модель

PopularityRecommender — базовая рекомендательная модель, ранжирующая товары по количеству взаимодействий и исключающая уже приобретённые товары.

## Тестирование

Автоматические тесты проверяют обучение модели, ранжирование, ограничение количества рекомендаций и обработку ошибочных входных данных.
